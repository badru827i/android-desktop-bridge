# Android Desktop Bridge — Android V1

This module is the first runnable UI prototype for the project.

## What V1 has

- Full-screen lightweight desktop shell
- 720p-oriented adaptive layout
- Taskbar / Apps launcher
- Simple demo window
- Minimal effects: no blur, no heavy transparency, no long animations
- Landscape-first layout
- No root required

## Important

This V1 is the **desktop UI prototype only**. It does not yet provide USB video output, HDMI/DisplayPort conversion, or full control of every Android app.

Those parts will be added as separate modules after the shell is stable.

## Build

Open `android-app` as an Android Studio project and build the `app` module.

Minimum Android version: API 26.
Target SDK: API 35.
